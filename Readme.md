# Imaginação é Arte - Landing Page

This is a front-end of a landing page for the company "Imaginação é Arte" focused on promoting the company's brand and services.

Repository: [https://github.com/silvadouglasFull/imaginacaoArteWeb](https://github.com/silvadouglasFull/imaginacaoArteWeb)

## ✨ Features

- Responsive design for different screen sizes.
- Sections for services, portfolio, and contact information.
- Modern and clean user interface.

## 🛠️ Technologies Used

This project was built using the following technologies:

- **React:** A JavaScript library for building user interfaces.
- **Vite:** A modern front-end build tool that provides a faster and leaner development experience.
- **TypeScript:** A typed superset of JavaScript that compiles to plain JavaScript.
- **HTML5 & CSS3:** For structure and styling.

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

You will need [Node.js](https://nodejs.org/) (which includes npm) installed on your machine.

### Installation & Running

1.  **Clone the repository:**

    ```sh
    git clone https://github.com/silvadouglasFull/imaginacaoArteWeb.git
    ```

2.  **Navigate to the project directory:**

    ```sh
    cd imaginacaoArteWeb
    ```

3.  **Install dependencies:**

    ```sh
    npm install
    ```

4.  **Run the development server:**
    ```sh
    npm run dev
    ```
    Open your browser and navigate to the local URL provided in the terminal (usually `http://localhost:5173`).
